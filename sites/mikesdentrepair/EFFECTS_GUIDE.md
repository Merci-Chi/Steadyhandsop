# Mikes Quality Dent Repair — Luxury overlay collection

## Start here
- Open `index.html` for the completed site.
- Open `effects-preview.html` to toggle and compare six independent effects over the REAL website.
- Each effect is an individual CSS file in `assets/effects/`.
- `06-cursor-halo.js` powers the desktop pointer effect.

## Palette
- Obsidian Black `#060C0D`
- Deep Teal `#102729`
- Sea Glass `#61CBB8`
- Light Aqua `#78E0CD`
- Soft Pearl `#EFF4F1`

## Effects
1. `01-aurora.css` — Body class `fx-aurora`.
2. `02-film-grain.css` — Body class `fx-grain`.
3. `03-cinematic-vignette.css` — Body class `fx-vignette`.
4. `04-precision-grid.css` — Body class `fx-grid`.
5. `05-light-sweep.css` — Body class `fx-sweep`.
6. `06-cursor-halo.css` and `06-cursor-halo.js` — Body class `fx-cursor`.

All six CSS files are included as separate link tags. Toggle an effect by adding or removing its body class, e.g. `<body class="fx-aurora fx-grain fx-vignette">`. The default has effects 1–3 enabled; the others are optional. The dedicated presentation layers are fixed, click-through (`pointer-events:none`), and ignore screen readers. Animations respect `prefers-reduced-motion`. Effects are aesthetic and may be omitted for low-power devices.
